❯ One question: Can I play different games in this one directory?  Will the map file or other generated files (transcript?) overwrite each other?

Yes, you can play different games in the same folder. Every generated file is named after its story file, so each game gets its own set:

┌─────────────────────────────┬──────────────┬──────────────────────┬─────────────────────────┐
│            File             │   Made by    │     For zork1.z3     │     For moonmist.z5     │
├─────────────────────────────┼──────────────┼──────────────────────┼─────────────────────────┤
│ Map                         │ zplay_llm.py │ zork1.map.json       │ moonmist.map.json       │
├─────────────────────────────┼──────────────┼──────────────────────┼─────────────────────────┤
│ Map PDF                     │ zmap_pdf.py  │ zork1.map.pdf        │ moonmist.map.pdf        │
├─────────────────────────────┼──────────────┼──────────────────────┼─────────────────────────┤
│ Transcript (script command) │ both players │ zork1.transcript.txt │ moonmist.transcript.txt │
├─────────────────────────────┼──────────────┼──────────────────────┼─────────────────────────┤
│ Saved game (default name)   │ both players │ zork1.sav            │ moonmist.sav            │
└─────────────────────────────┴──────────────┴──────────────────────┴─────────────────────────┘

There are three things to watch for:

1. Two story files with the same name but different extensions (say zork1.z3 and zork1.z5) would share all of these files.
   - Saved games: restore checks which game a save belongs to and refuses one from a different game, so nothing breaks.
   - The map: the map file records which game it belongs to. If it's from a different game, the tracker ignores it and starts a new map, but it then saves that new map over the old file, so the other game's map would be lost.

   The fix is to rename one of the story files so their names differ.
2. Transcripts are added to, never replaced. Each script session appends to the same file, which is useful as a running log. Delete it if you want a fresh one.
3. The save prompt suggests the same file name every time. Saving again with the suggested name replaces your previous save. To keep several, type a different name at the prompt, such as zork1-before-troll.sav.

If you'd like, I can fix the map issue in point 1 next time, so a map from a different game is never overwritten.
